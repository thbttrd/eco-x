# Epic 8: Application Information

## Overview

Display application information (name, version) in the UI header.

**Package:** ecox-client
**Feature File:** `epic08_application_info.feature`

---

## User Stories

### US-8.1: Display Application Version

**As a** user
**I want to** see the application version in the header
**So that** I know which version of the platform I am using

**Acceptance Criteria:**
- Display version number in the header
- Version badge has proper styling (green background)
- Version is read from package configuration

---

### US-8.2: Display Application Name

**As a** user
**I want to** see the application name in the header
**So that** I can identify the platform

**Acceptance Criteria:**
- Display "EconoScope" as the application name
- Name is prominently displayed in the header
